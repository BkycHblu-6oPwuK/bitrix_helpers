Главный модуль битрикс, куки

оставляем только `Распространять куки на все домены (только для https)` и `Устанавливать для кук авторизации атрибут secure (только для https)` (вроде так по дефолту)

php api в `/local/modules/beeralex.api/lib/ApiProcessResultTrait.php` - вырезает из заголовков все `Set-Cookie` из get запросов (на одном домене тоже актуально)
а api nuxt в `/nuxt/server/utils/api.ts` - в целом вырезает куки PHPSESSID (на одном домене удалить, сессия нужна)
так же нужно чтобы F_USER id сохранялся в куки, в этом помогает настройки Интернет магазина:

`Запоминать корзину неавторизованного пользователя`
